PROMPTS YOU OWN

Tell each agent exactly what to look for

Every agent ships with a sensible default. Replace it with your own instructions: point Security at the OWASP Top 10, or have Code Quality enforce your team's naming conventions. A global prompt sets the baseline; per-repository prompts override it.

  • 01Global review instructions across all repos
  • 02Per-repo overrides for monoliths, services, mobile apps
  • 03Reviews cached by PR + head SHA, so edits cost nothing until code changes

WHY A TEAM

One generalist misses what five specialists catch

A single prompt asked to cover everything produces a paragraph. Focused agents produce findings you can act on, and they run in parallel, so the whole team finishes in the time one would.
